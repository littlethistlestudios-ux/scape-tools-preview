How this maps to the spec

The Mrao file is read as the engine expects it — R metallic, G roughness, B ambient occlusion, A height — and rewired for the viewer's material, so what you see here is the same data the Triplanar shader will get.

Normals are treated as OpenGL. If a library material came out DirectX, bumps will look pressed in; tick Flip normal Y to confirm, then fix the source rather than the file.

Colour and Glow are look-development tools. Export as new material bakes tint, hue, saturation and brightness into a new BaseColor, and the glow into an _Emissive map, under a new name — the original set is never touched, and a small recipe file in the zip lets anyone re-apply the same settings. Glow still needs an emissive slot in the engine material, which the Triplanar shader doesn't have yet.

16-bit PNGs are decoded at full depth and shown at 8-bit, which is all a screen can display. Sizes, bit depth and missing channels are reported under Checks.
